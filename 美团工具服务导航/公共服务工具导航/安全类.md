| **KMS 密钥管理服务** | 92 | 统一密钥管理 | KMS提供统一的密钥管理服务，消灭各业务系统存储在配置文件、代码、ZK中明文，提升业务安全性。 简单介绍：支撑公司业务的众多服务中，大多需要诸如数据库密码这种敏感配置。而KMS出现之前，这些配置可能直接写在代码里、保存在配置文件里、使用MCC/Lion管理等。但这些方式都有一个共同的缺点：都是明文形势保存、传输这些敏感的秘钥，KMS就是为了解决这个问题而诞生的。 KMS 即 Key Management Service，为公司所有业务提供统一的密钥管理服务，消除各业务系统存放在配置文件、代码、ZK/MCC/Lion 等中的明文密码，提升安全性。 功能：KMS目前提供密钥管理和加解密服务。 使用场景：当你的服务里要配置明文密钥时，可以将密钥配置的 KMS，代码里填上密钥标识，即可减少密钥泄漏的风险。当您的数据库里有敏感数据时，使用 KMS 加解密服务保护您的数据，可以减少数据泄漏的风险。 | 🔜 | |
| **Tokenization 敏感信息脱敏服务** | 90 | 敏感信息脱敏 | 用户敏感信息数据是美团和用户的重要资产，一旦泄漏将对美团和用户造成不可估量的损失。保护美团用户数据安全符合公司长期利益，符合以客户为中心的价值观。当前美团缺乏整体的数据加密方案，导致用户数据过度暴露，明文数据过度使用，数据泄漏的风险大大增加，表现在以下几个方面： 1）海量数据明文存储；2）明文传输；3）业务BD、客服、RD乃至底层运维人员可以大量接触明文数据；4）公司内部存在过多的应用可以批量获取明文数据；5）公司内部敏感信息数据的流向、监管能力空白。 根据集团《数据安全管理规定》，其中用户的手机号、邮箱、卡号、证件号等信息被定为C-4绝密数据，敏感信息脱敏服务能够针对上述场景提供一套完整化解决方案，包括不限于敏感信息存储、加解密、数据交换等。 | 🔜 | |

| **SFTP sftp服务平台** | 91 | 安全数据存储交换 | SFTPS是一套适用于公司内外部的、高可用、强稳定和高安全级别的数据存储交换平台。主要功能有： 1.产品技术类：RD希望实现数据存储上传、下载的自动化； 2.运营类：需要对外（美团公司以外的人员）提供密级资料； | 🔜 | |
